## 🤝 Contributing

### Adding Images
1. Choose the appropriate category folder
2. Follow naming conventions (lowercase, hyphens, descriptive)
3. Optimize images for web (compress, appropriate format)
4. Update README files if needed

### File Naming Convention
```
✅ Good: main-logo.png, dashboard-screenshot.jpg, hero-banner-1200x400.png
❌ Bad: Logo1.PNG, Screen Shot 2024.jpg, banner.jpeg
```

### Image Guidelines
- **Format**: PNG for logos/icons, JPG for photos, SVG for vectors
- **Size**: Optimize for web (<1MB preferred)
- **Dimensions**: Include in filename for banners/specific sizes
- **Quality**: High enough for intended use, compressed for web
