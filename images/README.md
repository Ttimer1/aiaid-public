## 🎨 Image Guidelines

### Formats
- **PNG**: Logos, icons, screenshots (for transparency)
- **JPG**: Photos, banners (for smaller file sizes)
- **SVG**: Vector graphics (logos, icons for scalability)
- **WebP**: Modern format for web optimization

### Naming Convention
- Use lowercase with hyphens: `main-logo.png`
- Be descriptive: `dashboard-dark-theme.png`
- Include dimensions when relevant: `banner-1200x400.png`

### Optimization
- Compress images for web use
- Maintain aspect ratios
- Provide multiple sizes when needed
- Use appropriate color profiles (sRGB for web)

## 🔍 SEO Optimization

All images should include:
- Descriptive filenames
- Alt text descriptions
- Proper dimensions
- Optimized file sizes
- Relevant keywords in descriptions
