# Banners

This directory contains promotional banners and marketing assets.

## Available Banners

### Marketing Banners
- `hero-banner.png` - Main promotional banner (1200x400)
- `social-media-banner.png` - Optimized for social platforms (1200x628)

### Platform-Specific
- `github-banner.png` - GitHub repository banner
- `newsletter-banner.png` - Email marketing campaigns

## Specifications

- **Hero Banner**: 1200x400px - Website headers, landing pages
- **Social Media**: 1200x628px - Facebook, Twitter, LinkedIn sharing
- **GitHub**: 1280x640px - Repository banner image

## Usage Guidelines

- Banners are designed for digital marketing
- Maintain aspect ratios when resizing
- Use appropriate banner size for each platform
- High-contrast text ensures readability
