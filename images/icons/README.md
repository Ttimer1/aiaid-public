# Icons

This directory contains icon sets and favicon collections.

## Available Icons

### Application Icons
- `app-icon.png` - Primary application icon (512x512)
- `icon-128.png` - Large icon for desktop applications (128x128)
- `icon-64.png` - Medium icon for toolbars (64x64)
- `icon-16.png` - Small icon for system tray (16x16)

### Web Icons
- `favicon.png` - Website favicon (32x32)
- `apple-touch-icon.png` - iOS home screen icon (180x180)

## Specifications

All icons are provided in PNG format with transparency support:
- **512x512**: High-resolution app stores
- **128x128**: Desktop applications
- **64x64**: Toolbar icons
- **32x32**: Browser tabs (favicon)
- **16x16**: System notifications

## Usage Guidelines

- Icons maintain consistent design language
- Use appropriate size for each context
- Preserve transparency for proper layering
