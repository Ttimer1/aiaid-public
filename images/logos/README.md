# Logos

This directory contains all logo variations and branding assets for AI Aid.

## Available Logos

### Primary Logos
- `main-logo.png` - Primary AI Aid logo for general use
- `logo-dark.png` - Dark variant optimized for light backgrounds
- `logo-light.png` - Light variant optimized for dark backgrounds

### Format Variations
- `logo-square.png` - Square format ideal for social media profiles
- `logo-horizontal.png` - Horizontal layout for headers and banners

## Usage Guidelines

- Use the main logo for primary branding
- Choose dark/light variants based on background contrast
- Maintain minimum padding around logos
- Do not modify colors or proportions
- Provide adequate contrast for accessibility
